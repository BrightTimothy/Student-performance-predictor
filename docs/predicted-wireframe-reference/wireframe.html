Advisor dashboard

Advisor

Desktop: sidebar + 3 summary cards + compact filter row + ranked list as bordered card-rows (never a spreadsheet grid — no colour-washed backgrounds, only a small muted dot carries risk). Mobile: sidebar collapses to a hamburger, summary cards become a horizontal scroll strip, filters collapse into a single "Filters" pill that would open a bottom sheet, and every row becomes a full-width stacked card so nothing is truncated. No financial data appears on this screen at all.

Student profile

Advisor

Desktop: two-column — left column carries identity, bursary context and actions; right column carries the explainability content (gauge, reason bars, trend, log). Mobile: single column, everything stacks in the same reading order, and the three actions become a sticky bar pinned to the bottom of the screen so they're always one thumb-reach away. The bursary chip is deliberately grey and quiet — same visual weight as a metadata label, never a status alert.

Advisor

Both keep the form to two fields — outreach type and a note — because friction here is the single biggest risk to the Flag→Contacted loop actually being honest.

09

Escalations

Coordinator · HOD

Desktop & mobile share the same card-row pattern used on the advisor dashboard, for continuity across roles — flags unactioned 14+ days reach this list automatically (a 7-day reminder goes to the advisor first, quietly, before it ever surfaces here). The only control is Message advisor — never a student action, and never automated escalation beyond this point; the HOD decides whether to act.
